Contribute on GitHub

  1. Fork the repository on GitHub and clone your fork.
  2. Set it up: python3 -m venv .venv && .venv/bin/pip install -e ".[dev,e2e]"
  3. Make your change with tests, and run .venv/bin/pytest
  4. Open a pull request. Bugs and ideas are welcome as issues.
